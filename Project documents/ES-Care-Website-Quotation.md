## 1. Project summary

Design, build, and deliver a branded WordPress website for E&S Care Services LLC, including a custom marketing theme and a custom **ES Care Portal** plugin for job seekers, employers, applications, assessments, employment forms, service requests, and public contact.

---

## 2. Scope of work

### A. Public marketing website (custom theme)

- Home page with branded hero, value messaging, and CTAs (Apply Now / Request Staffing)
- About Us, Services, Who We Staff, Core Values
- Employers and Job Seekers landing pages (linked into the portal)
- Contact page with portal Contact Us form
- Legal / policy pages: Privacy Policy, Code of Conduct, Equal Opportunity
- Responsive layout for desktop and mobile
- Primary and footer navigation
- Customizer fields for phone, email, hours, and address

### B. Careers & staffing portal (custom plugin — ES Care Portal)

- Separate portal accounts (not WordPress site users)
- Job seeker registration, login, profile, job browse/apply, resume upload
- Employer registration, email verification, admin approval, job posting (pending until staff publish)
- Portal admin dashboard: users, jobs, applications, contact messages
- Assessments and employment forms
- Service requests / Contact Us inbox
- SMTP-ready transactional email (verification, applications, moderation)
- Private resume / file storage with retention settings
- WordPress admin: Overview, Settings, Health checks
- Optional Elementor widgets for portal modules

### C. Setup & handover

- Theme and plugin packaging / install guidance
- WordPress configuration guidance (pages, menus, settings)
- Domain / hosting / email coordination support (as agreed)
- Handover documentation (credentials & management guide)
