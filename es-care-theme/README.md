# E&S Care theme

Public marketing theme for **E&S Care Services LLC**. Install as `wp-content/themes/es-care`.

Activate it after **ES Care Portal** is active. On activation the theme creates marketing pages, assigns templates, sets the Home page as the front page, and builds primary/footer menus. It does **not** recreate portal pages (Sign In, Register, Dashboard, Careers, Contact Us).

Customizer → **E&S Care contact** holds phone, email, hours, and address.

Apply Now, login, register, careers, and Request Staffing all link into the existing portal.
