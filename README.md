# ES Care Services LLC — WordPress

WordPress project for [ES Care Services LLC](https://escare-services.com). The custom plugin **ES Care Portal** handles job-seeker and employer accounts, careers, applications, assessments, and contact forms.

## Plugin

See **[es-care-portal/README.md](es-care-portal/README.md)** for install, pages, shortcodes, roles, settings, privacy, and tests.

Copy `es-care-portal/` into `wp-content/plugins/` (or keep it there in this repo) and activate it in WordPress.

## Requirements

- WordPress 6.0 or later
- PHP 7.4 or later
- Elementor optional (portal widgets)
